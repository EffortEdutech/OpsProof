# FireMaint V1 — Administrator & Technician User Guide

## Administrator

Core tasks:
1. Sign in.
2. Create client/site/building.
3. Register equipment.
4. Create maintenance plan.
5. Create job.
6. Assign technician.
7. Review findings.
8. Generate/review report.
9. Issue report.
10. Monitor dashboard.

## Technician

Core flow:

```text
Login
 ↓
My Jobs
 ↓
Download Offline
 ↓
Start Job
 ↓
Open Equipment
 ↓
Inspect
 ↓
Add Finding/Photo
 ↓
Complete Equipment
 ↓
Submit Job
 ↓
Sync
```

## Technician Rules

- inspect only assigned jobs
- do not clear app storage when unsynced work exists
- verify Sync = complete before sign-out where possible
- use finding when defect-triggering item fails
- add clear photo evidence

## Admin Rules

- do not hard-delete historical records
- review findings before issuing report
- void, never overwrite, an incorrect issued report
- use template versions for inspection changes

## Support Information to Capture

When reporting an issue:
- user
- job number
- asset code
- inspection ID if known
- report number if relevant
- approximate time
- screenshot
- sync status

## Principle

> **Administrators control the workflow. Technicians capture evidence at the asset.**
