# Demo Story

1. Office creates/schedules job.
2. Technician opens mobile PWA.
3. Technician inspects FE-001.
4. One defect creates finding + photo.
5. Job submitted.
6. Report generated.
7. Supervisor issues.
8. Client opens portal and downloads report.
9. Dashboard shows status/findings.

# Demo Dataset Requirements

- one GENERATED report

# Pilot Acceptance

A customer should not be considered live until:
- first technician job completed
- report generated correctly
- customer approves report layout
- portal access confirmed
- no blocking data/import issue

## Principle

> **A demo should prove the workflow. Onboarding should reproduce it for a real customer.**
